1. What this policy covers

This policy distinguishes this static website, the current local Windows prototype, and a possible future TikTok integration. It describes the project's current scope; it does not describe an available public application.

The website does not accept media uploads, create accounts, or connect to TikTok. The desktop tool is used privately by its developer.

2. Website visits and hosting

The site's own files contain no analytics, advertising, tracking scripts, forms, embedded videos, external fonts, cookies, or browser storage. The site operator does not collect visitor submissions or operate a visitor database through these pages.

When hosted on GitHub Pages, GitHub logs visitor IP addresses for security purposes. Hosting is subject to GitHub's Privacy Statement. The absence of site tracking does not mean that the hosting provider processes no technical data.

3. Current local video processing

The core workflow processes selected Twitch videos locally on Windows. Local project files can include source video and audio, transcripts and word timestamps, clip boundaries, editorial notes, subtitles, titles, descriptions, and exported videos. Source material can contain voices, faces, usernames, and other information about people appearing in the recording.

Those project files are not included in this website. Visiting it does not upload or expose them. The local workflow does not require a TikTok account connection. Media intentionally shared with a third party is subject to that party's policies and requires an appropriate authorisation or other legal basis.

The project does not sell personal data or use these pages for advertising.

4. Planned TikTok connection - not implemented

A future version may use TikTok OAuth to request permission from the account holder. The intended scope is video.upload, for sending an explicitly selected video without automatically publishing it. The creator would continue through TikTok's editing flow and complete any post in the mobile app.

This would involve sending the selected video to TikTok and handling connection information such as an account identifier, authorisation scopes, and access or refresh tokens. The website would not ask for a TikTok password. This connection, consent flow, and transfer are not currently implemented.

If developed, connection data is intended to remain in local Windows storage, separate from this static website. The storage mechanism, protections, retention rules, and user controls still need to be implemented and validated. No claim of encryption or completed credential-management controls is made here.

5. Retention, deletion, and disconnecting

Current local media, transcripts, metadata, and exports remain until the developer removes them. No automatic deletion schedule is implemented. Local files and any copies or backups must be managed separately.

A future disconnect feature is intended to revoke TikTok authorisation and remove locally stored connection credentials; this control has not yet been built. There is no current TikTok connection in this workflow to disconnect.

Deleting a local file would not delete the original Twitch video, a copy already sent to TikTok, or material held by another recipient. Such copies must be managed with the relevant service.

6. Contact and future changes

For privacy questions, requests concerning local project data, or support, contact dinor1201@gmail.com.

If you choose to email this address, your email address, message, and any attachments are handled through the contact mailbox to address your request. This is separate from browsing this static website; email providers also process the correspondence under their own policies. Do not send passwords, access tokens, or unnecessary personal data.

Before processing data on behalf of other users or enabling a public integration, the applicable legal basis, rights process, retention practices, and security measures must be reviewed and implemented.

This policy must be updated to reflect actual changes before new data processing begins. It is not a substitute for implementing the controls described as planned.
